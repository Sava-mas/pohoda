# Погода — порівняння моделей

Сторінка прогнозу для Львова й Карпат: https://sava-mas.github.io/pohoda/

Порівнює провідні погодні моделі (ECMWF, ICON, UKMO, ARPEGE, GFS, AIFS, регіональні моделі високої роздільності),
показує попередження на 48 годин, погодинний графік на 3 дні та перевірку моделей за останні 2 дні.

## Будова

- `index.html` — розмітка сторінки
- `css/style.css` — оформлення
- `js/config.js` — місця за замовчуванням і список моделей
- `js/app.js` — завантаження даних і показ
- `sw.js`, `manifest.webmanifest`, `icons/` — вебзастосунок: встановлення на пристрій і робота без мережі

Сервера немає: дані завантажуються просто в браузері з [Open-Meteo](https://open-meteo.com/) (CC BY 4.0, некомерційне використання).
Список місць зберігається лише на пристрої користувача.
